Kicker: Personal

I wanted a personal website again, which is a slightly odd thing to want in 2026. Everything I make already has somewhere to go — photographs to one app, songs to another, work to a third. Each of those places is happy to host what I make on the condition that it looks like everything else there.

So this is the other thing. A place where the photographs are large, the songs are unfinished, and nothing is optimised for anyone's feed.

## What goes here

Four things, roughly:

- Photographs I took and wanted to keep
- Music made with too many pedals and not enough endings
- Software I built because the alternative was doing the task by hand
- Notes, occasionally, when something is worth writing down

The common thread is that none of it is finished. That used to feel like a reason not to publish. I've decided it's the reason to.

> The work you'd only show once it's done is usually the work you never show.

## How it's built

Plain HTML, CSS and about a hundred lines of JavaScript. No framework, no build step beyond a script that reads what's in a folder. If I want a new photograph on the site I put the file in `images/` and the site grows by one photograph.

That constraint is doing a lot of work. It means adding to this place is easier than not adding to it, which is the only way a personal site survives past its first month.
